### Introduction

Data types shouldn't be too difficult to understand. The meaning is in the name itself! words, numbers, these are all ways to store and use data. To allow us to do this, Java gives us multiple data types. We

divide data types into primitive and non-primitive data types. Primitive data types are inbuilt data types and non-primitive data types are things that we can use or manipulate. In this lesson, you'll learn about the different primitive data types. In later lessons, you'll learn about non-primitive data types like arrays or classes.
