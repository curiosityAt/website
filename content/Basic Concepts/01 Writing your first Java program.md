### Installation 

Before you learn about important programming topics like operators, data types, loops and many more, it's useful to know the basic structure of a Java program. Before you create your first Java program,  you'll need to choose an IDE or a code editor to write an execute the program. In this video lesson and later lessons as well, I'll use a code editor called Visual Studio Code. There are other environments that you can use to program like BlueJ or Eclipse. It's completely up to you what IDE you choose. I would recommend BlueJ since it's a lot easier to work with for beginners. 

You'll also need to install something called the JDK or the Java Development Kit which contains all the tools and libraries necessary to program in Java. To help you install the JDK and BlueJ, I added the links to the installation. Download the latest versions.

To install the JDK - [Java installation](https://www.oracle.com/java/technologies/downloads/)

To install BlueJ - [BlueJ installation](https://bluej.org/)
