### Introduction

Data types are helpful to use different types of values in a program, but we can't just keep printing char values or int values. Eventually, it becomes important to store numbers or the result of arithmetic expressions. This is where we use variables.

![Variables in Java](https://youtu.be/ALq-5JoTeG0)

### Syntax

```Java
public class VariablesInJava{
	public static void main(String[]args){
	
		int a; // Declaring an int variable called a
		a = 22; // Initialising the int variable a
		a = 5; // Changing the variable a and assigning it a new value 5
		
		System.out.println(a); // Using a println statement to print variable a			
		}
}
```
